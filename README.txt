# Meu Site de Conteúdos

## Como configurar

1. Abra `script.js`.
2. Troque:
   `const TELEGRAM_USERNAME = "seu_telegram";`
   pelo seu username do Telegram, sem `@`.
3. Coloque suas imagens dentro da pasta `imagens`.
4. No mesmo arquivo, altere títulos, preços e nomes das imagens.
5. Abra `index.html` no navegador para testar.

## Publicação gratuita

Você pode publicar estes três arquivos em serviços de hospedagem de páginas estáticas, como GitHub Pages ou Cloudflare Pages.

O site é responsivo e funciona em celulares.

Observação: use apenas conteúdo que você tenha direito de vender/distribuir e respeite as leis e regras das plataformas usadas.
